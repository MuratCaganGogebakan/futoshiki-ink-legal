# Futoshiki Sky website

Static, dependency-free pages for Futoshiki Sky’s App Store marketing, support, privacy, terms and credits URLs.

Futoshiki Sky 1.1 and later include all twelve constellations, Daily Challenges and unlimited Free Play for free, with no in-app purchases or subscriptions. Privacy disclosures retain the historical RevenueCat record explanation for older builds; no current purchase SDK is described or credited.
