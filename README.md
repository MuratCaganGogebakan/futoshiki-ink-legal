# Futoshiki Ink website

Static, dependency-free pages for Futoshiki Ink’s App Store marketing, support, privacy, and terms URLs.

## App Store Connect URLs

When published at `https://muratcagangogebakan.github.io/futoshiki-ink-legal/`:

- Marketing URL: `https://muratcagangogebakan.github.io/futoshiki-ink-legal/`
- Support URL: `https://muratcagangogebakan.github.io/futoshiki-ink-legal/support.html`
- Privacy Policy URL: `https://muratcagangogebakan.github.io/futoshiki-ink-legal/privacy.html`
- Terms of Use URL: `https://muratcagangogebakan.github.io/futoshiki-ink-legal/terms.html`

## Local preview

Serve this directory with any static HTTP server. No build step or JavaScript is required.

## Before release

- Confirm the developer/business name, city, country, and support email.
- Confirm the App Store privacy disclosures match the shipped SDK configuration.
- Have the privacy policy and terms reviewed for the release territories.
- Update the effective dates whenever the legal text changes materially.
